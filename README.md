# Youtube-Comment-photo-blocker
This extensions blocking download and show GIF/Image in youtube comments 

## Установка в Google Chrome

1. Скачайте архив проекта и распакуйте его. На GitHub нажмите **Code → Download ZIP**.
2. Откройте `chrome://extensions` в Google Chrome.
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой находится файл `manifest.json`.
5. Откройте YouTube. Если вкладка уже была открыта, обновите её.

## Как пользоваться

По умолчанию расширение скрывает фото и GIF в комментариях YouTube.
